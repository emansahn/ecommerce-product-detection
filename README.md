# E-commerce Product Detection & Inventory Dashboard

## Project Overview
This project detects and classifies e-commerce products in images, counts items per type, and visualizes inventory data. The goal is to create a proof-of-concept inventory assistant for online stores or warehouses.

## Motivation
- Apply computer vision techniques to a real-world e-commerce scenario.
- Showcase Python, OpenCV, and AI skills on a professional project.
- Build an interactive dashboard for visualization (Streamlit planned).


## Visualization
- Annotated images with bounding boxes and labels.
- Counts per product type.
- Optional: Streamlit dashboard for interactive inventory management.
